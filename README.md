# TripAdvisor Dashboard

An interactive Tableau dashboard project created to analyze TripAdvisor travel and hotel review data.

## Features
- Hotel and travel review analysis
- Rating distribution insights
- Location-based trends
- Customer feedback visualization
- Interactive filters and dashboards

## Tools Used
- Tableau
- Excel
- Data Visualization

## Dashboard Insights
- Identified highly rated locations and hotels
- Analyzed customer review patterns
- Visualized travel trends and ratings
